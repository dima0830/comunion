# Invitación de Primera Comunión

Invitación web (Vue 3 + Vite) publicada en GitHub Pages.

## Personalizar

- **Nombre, fecha, lugares, padres y padrinos:** `src/datos.ts`
- **Video de fondo (opcional):** `src/assets/videos/video-fondo.mp4` y su imagen de carga `src/assets/images/video-fondo-poster.webp`
- **Video de vestimenta (opcional):** `src/assets/videos/dresscode.mp4`
- **Fotos de la galería:** `src/assets/images/gal1.webp`, `gal2.webp`, …
- **Música (opcional):** cualquier `.mp3` en `src/assets/audio/`
- **Guirnaldas:** `src/assets/images/guirnalda-{arriba,divisor,abajo}.webp`

## Desarrollo

```bash
npm install
npm run dev
```

Cada push a `main` se publica solo en GitHub Pages.
